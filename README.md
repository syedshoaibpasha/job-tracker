📋 Job Application Tracker

A simple and user-friendly Job Application Tracker built with Flask and SQLite. It helps users manage their job applications in one place and keep track of application status, dates, links, and notes.

✨ Features

* ➕ Add new job applications
* ✏️ Edit existing applications
* 🗑️ Delete job applications
* 🔎 Search jobs by company or job role
* 🔽 Filter applications by status
* 📊 Dashboard with application statistics
* 📅 Track application dates
* 🔗 Save and open job posting links
* 📝 Add notes for each application
* 🔍 Display a message when no matching jobs are found

🛠️ Technologies Used

* Python
* Flask
* SQLite
* HTML5
* CSS3
* Jinja2

⚙️ How to Run

1. Clone the repository

git clone https://github.com/syedshoaibpasha/job-tracker.git

2. Open the project folder

cd job-tracker

3. Install Flask

pip install flask

4. Run the application

python app.py

5. Open in your browser

http://127.0.0.1:5000/

🖥️ Application

The application provides a dashboard where users can view and manage their job applications, search and filter opportunities, update application status, and store useful job links and notes.
